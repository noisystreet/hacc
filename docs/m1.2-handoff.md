## 2. 已拍板的决策（不要再重新讨论）

见 `docs/m1.2-il-to-llvm-plan.md` §7：

1. **`coolicc` 直接链接 EDG 前端库**（方案 A）。
2. **IL 文件 = EDG 二进制 IL**（`il_write`/`il_read`），非文本解析。
3. **翻译核心 = 独立库** `src/device/il_to_llvm/`（便于阶段 B 复用与单测）。
4. **IL 须能 dump 成人类可读**（见 §7.1）。

### 2.1 关于「人类可读 dump」的关键坑（务必知道）

- `cdisp <file.cil>`（二进制 IL → 文本）**对含任意属性的 IL 断言崩溃**
  （`il_display.c:210` `disp_ptr_value`，exit 134）——**EDG 上游 bug**，与
  `RECORD_UNRECOGNIZED_ATTRIBUTES` 无关（`aligned` 等已知属性同样触发）。
- **可靠路径**：`cpfe --il_display`（编译期 dump 内存 IL，**不经过** `cdisp`）。
  M1.2.0 已用此路径让 `coolfe++` 落文本。
- 若将来只有二进制 IL 需要 dump：自建 `hacc-il-dump`（调 `il_read` + `do_il_display`，
  绕过 `cdisp` 的 main）。**尚未实现**，非阻塞。

## 6. 下一步：M1.2.1（本次会话的起点）

**目标**：`coolicc` 链接 EDG 库，`il_read` 读回 IL，**打印 file scope 的 routine 列表**。
**验证**：能列出内核名（如 `empty_kernel`）。

### 6.1 建议步骤

1. **CMake**：`HACC_WITH_EDG=ON` 时给 `coolicc` 链接 EDG 库（参考 `fetch_edg.sh` 的构建产物；

   - 遍历 file scope region 的 routine 列表，打印名字。
3. **`coolicc` CLI**：新增 `--emit=il-list`（或类似）从 `.cil` 读回并打印。
4. **测试**：golden —— `empty_kernel.cu` → `.cil` → `coolicc --emit=il-list` 输出含 `empty_kernel`。
